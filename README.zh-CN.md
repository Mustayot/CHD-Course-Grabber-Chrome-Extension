# 长大教务抢课助手 (Chrome 扩展)

长安大学本科教务系统(bkjw.chd.edu.cn, 正方 eams)自动抢课扩展。
**无需处理登录** —— 扩展复用你浏览器里已有的登录会话。

## 功能

- **自动爬取课程列表**：从选课页抓取真实的教学班ID、课程代码、课程序号、教师、校区
- **实时人数显示**：每个教学班显示 `已选/上限`，满员红色标注
- **多课程优先级**：添加多个目标，按顺序抢，抢到第一个即停
- **双模式**：
  - ⚡ **快速**：默认 3 秒一次（可调），满员自动降频
  - 🕐 **蹲守**：默认 60 秒一次，适合开抢前挂机
- **防封退避**：连续失败自动拉长间隔（3s → 5s → 10s → 30s）
- **满员自动切蹲守**：所有目标满员时自动降频到 60s，避免频繁请求被封
- **每次提交都有反馈**：✅ 成功 / ⛔ 满员 / ❌ 失败，面板 + 日志可见
- **通知**：成功时声音 + 浮动提示

## 安装（开发者模式）

1. Chrome 地址栏输入 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点 **"加载已解压的扩展程序"**
4. 选择本文件夹（source/）
5. 打开教务选课页，右上角出现 🎯 面板

## 使用

1. 登录教务系统并进入选课页（`http://bkjw.chd.edu.cn/eams/stdElectCourse.action`）
2. 添加目标课程（两种方式）：
   - "课程库"标签 → 搜索课程 → 点"+目标"
   - 或直接输入：课程代码（如 `TB206001`）、课程序号（如 `TB206001.08`）、教学班ID（如 `420476`）、课程名
3. 选择模式：⚡ 快速(3s) / 🕐 蹲守(60s)
4. 点 **"开始抢课"**，抢到自动停止并通知

目标按从上到下优先级依次抢，抢到第一个即停止。

## 内部使用的接口

| 接口 | 用途 |
|---|---|
| `GET /eams/stdElectCourse!data.action?profileId=<id>` | 课程列表（教学班id、课程代码） |
| `GET /eams/stdElectCourse!queryStdCount.action?projectId=1&semesterId=262` | 每个教学班已选/上限人数 |
| `POST /eams/stdElectCourse!batchOperator.action?profileId=<id>&retakeDetail=` | 提交选课 |

## 注意事项

- 只在你**自己**的账号上使用，只抢自己真正需要的课
- 抢课频率太高可能触发学校风控，默认间隔已较保守
- 扩展不做登录，需要已有登录会话
